# ADR-0013 M5 商业化核心：套餐、能力开关、模板与只读分享

- 状态：已接受
- 日期：2026-11-14

## 背景

M5 原计划包含计费账单、管理后台、模板市场、分享协作、多语言与 `coding.assist`。其中支付/发票、评论、i18n 涉及外部依赖与产品决策，不适合在缺少支付渠道与法务确认时实现。本次交付商业化核心，其余明确 deferred。

## 决策

1. **套餐即配额预设**
   - `free / pro / team` 三档，切换时同时更新 `tenants.tier` 与 `quota_limits`。
   - 账单唯一事实仍是 `usage_ledger`；`/v1/billing/summary` 按能力/驱动/单位聚合。
   - 不实现支付、发票、退款；这些留到接入支付渠道后。

2. **租户级能力开关**
   - `tenant_capabilities(tenant_id, capability_id, enabled)`，缺省视为启用。
   - 能力列表过滤停用项，详情返回 404，新建任务返回 `CAPABILITY_UNAVAILABLE`。
   - 仅 owner/admin 可切换。

3. **项目模板**
   - 租户级模板，保存名称、描述与可选 payload；「用模板建项目」复制模板元数据。
   - 不做模板市场与跨租户共享。

4. **只读分享**
   - 随机 32 字节 token，库内只存 SHA-256；默认 7 天有效，可撤销。
   - 公开接口只返回项目/资产元数据与文本预览；不暴露音频/视频下载与原文件。
   - token 查找通过 `SECURITY DEFINER` 函数定位分享，随后进入该租户上下文，避免公开请求绕过 RLS。
   - 不做密码保护、访问统计与水印。

5. **评论与账单**
   - 项目级评论：成员可写，作者或 owner/admin 可删；按项目顺序返回。
   - `GET /v1/billing/statement` 输出月度对账单 JSON（明细 + 总额 + 任务数），不生成 PDF。
6. **coding.assist**
   - 能力包 + Claude Code driver，输入 `code_workspace`，输出补丁说明。
   - 代码执行仍走沙箱；gVisor 结论沿用 ADR-0012：正式对外开放前再评估。

## 明确 deferred

- 支付渠道、发票、退款、账单 PDF
- 实时协作（当前只有项目级评论）
- 多语言 UI
- 模板市场与跨租户分发
- 生成式视频镜头
- OpenCode / dsh driver

## 后果

正面：
- 套餐、配额、用量、能力开关形成闭环，可支撑内测收费。
- 分享链接可安全地只读传播，且不暴露租户数据。
- 模板降低重复建项目的成本。

代价：
- 没有支付时，套餐切换只是权限与配额变化，需人工计费。
- 分享只有文本预览，媒体资产无法在公开页播放。
- `coding.assist` 的隔离强度仍取决于 Docker 沙箱配置。

## 回滚条件

- 接入支付后，套餐切换必须改为支付回调驱动，禁止客户端直接改 tier。
- 若分享需要媒体预览，增加短期签名 URL 与访问审计，而不是公开对象存储。
- 若代码执行对外开放，先完成 gVisor/Firecracker 与网络白名单。
