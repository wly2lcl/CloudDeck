# 12 风险与待决策

## 风险登记

| ID | 风险 | 概率 | 影响 | 缓解 | 触发信号 |
|---|---|---|---|---|---|
| R1 | 第三方 agent CLI 版本变动导致适配失效 | 高 | 中 | 版本固定 + driver 契约测试 + 每版本回归样例 + 灰度 | 契约测试失败、事件结构变化 |
| R2 | 第三方 agent 的商用/托管条款不允许转售 | 中 | 高 | 法务核对；优先支持 BYOK 与自研 LLM driver；保留切换能力 | 收到 provider 政策通知 |
| R3 | 沙箱逃逸或越权访问 | 低 | 极高 | 只读根、非 root、默认无网、资源限制；M4 评估 gVisor | 安全扫描告警、异常网络请求 |
| R4 | 模型成本失控 | 高 | 高 | 单 job 预算、并发限制、预估+预扣、异常熔断 | 单 job 成本超预估 50% |
| R5 | 长任务可靠性（TTS/视频中断） | 高 | 高 | 最小可续单元 + checkpoint + 幂等步骤 + 部分成功 | 恢复后重跑量 >30% |
| R6 | GPU 容量不足或排队过长 | 中 | 中 | 双路由（本地/云）+ 队列优先级 + 按 tier 限流 | 平均排队 >10 分钟 |
| R7 | 内容链模型过度理想化，实际能力无法复用上游资产 | 中 | 高 | M3 前用真实小说验证；每个能力显式声明消费哪些上游 | 能力需要重复录入设定 |
| R8 | 平台抽象过重，简单能力接入成本高 | 中 | 中 | capability-sdk 提供模板与默认实现；新能力 ≤3 人日检查单 | 新能力接入超过 3 人日 |
| R9 | 移动端投入产比低 | 中 | 中 | 首版只做进度/播放/轻确认，不做编辑 | 移动端需求占开发 >25% |
| R10 | 版权与声音克隆合规 | 中 | 高 | 上传声明、音色授权、投诉下架、生成标识 | 出现权利人投诉 |
| R11 | 多租户数据隔离缺陷 | 低 | 极高 | RLS + 强制过滤 + 跨租户测试 + 审计 | 任何跨租户访问成功 |
| R12 | 文档与实现漂移 | 高 | 中 | 契约测试；文档变更随 PR；里程碑复核 | 新人按文档跑不通 |
| R13 | 凭据主密钥丢失或轮换失败 | 低 | 高 | `CREDENTIALS_KEY` 独立管理与备份；`CREDENTIALS_KEY_PREVIOUS` + rotate 接口支持轮换 | 密钥更换后解密失败 |
