# 00 产品定义

## 定位

CloudDeck 是 AI 内容生产工作台：把「一个想法」推进到「可发布的小说 / 剧本 / 有声书 / 视频」，并让每个环节可以由不同的 AI 引擎完成。

不是通用聊天机器人，不是低代码平台，不是模型训练平台。

## 目标用户

| 用户 | 痛点 | 我们提供 |
|---|---|---|
| 个人创作者 | 工具分散、上下文丢失、AI 味道重 | 一条链跑完，角色与设定全局复用 |
| 小型内容团队（2–10 人） | 协作靠网盘、版本混乱 | 项目级资产、版本、评论、权限 |
| MCN / 出版 / 有声机构 | 批量生产、成本不可控 | 批量任务、配额、成本上限、审计 |

## 首版能力

| 能力 ID | 名称 | 输入 | 输出 | 首版 |
|---|---|---|---|---|
| `novel.edit` | 小说编辑协助 | 稿件、设定库 | 稿件新版本、批注 | 是 |
| `script.generate` | 剧本生成 | 小说/大纲 | 剧本、分场表 | 是 |
| `audiobook.render` | 有声小说生成 | 稿件、角色音色 | 音频轨、章节包 | 是 |
| `storyboard.plan` | 分镜规划 | 剧本 | 分镜表、画面描述 | 是 |
| `video.render` | 视频合成 | 分镜、音频 | 视频文件 | 是（M4） |
| `coding.assist` | AI 编程 | 代码工作区 | 补丁、审查意见 | 否（M5 可选） |

能力之间不直接调用，只通过资产引用串联。

## 非目标（至少一年内）

- 不做通用 Agent 市场或插件应用商店
- 不做模型微调、推理集群自建
- 不做实时协作编辑器（先做版本 + 评论）
- 不做桌面端原生应用（Web 自适应 + 移动端即可）
- 不承诺任意第三方能力零代码接入（能力包仍需少量代码）

## 核心主张与验证方式

| 主张 | 验证 |
|---|---|
| 资产链比单点工具更省重复劳动 | 同项目内剧本复用小说的角色/设定，无需重填 |
| 引擎可插拔 | 同一能力切换 driver 不改客户端、不改平台 |
| 成本可控 | 每个 job 有预算上限，超限终止并留审计 |
| 多端一致 | Web 与移动端共用同一 API 与契约，能力上新客户端零改动 |

## 商业化路径

| 阶段 | 形态 | 凭据 | 计费 |
|---|---|---|---|
| A 起步 | 内测版 | 仅 BYOK | 免费 / 服务费 |
| B 目标 | 创作者 SaaS | BYOK 优先，试用额度池 | 订阅 + 额度 + 超量 |
| C 分支 | 企业私有化 | 客户自带 | 年度授权 + 实施费 |

A 是 B 的前两个里程碑，不是独立产品；C 是 B 的部署形态，不单独维护代码。详见 [ADR-0008](adr/0008-commercial-phasing.md)。

## 成功指标

首版（M3 结束）必须达到：

1. 10 万字小说 → 多角色有声书，全流程 ≤ 30 分钟（云端 TTS），可断点续作
2. 单章 TTS 失败重试后成功率 ≥ 99%，失败可定位到具体章节
3. 新增一个纯流水线能力（如分镜）≤ 3 人日，且不改平台代码
4. 单 job 成本偏差 ≤ 预估的 20%
5. Web 端完成从上传到播放的全流程；移动端能看进度、听成品

## 术语

| 术语 | 含义 |
|---|---|
| 能力 / capability | 对用户可见的一项生产工序，由 manifest 声明 |
| 能力包 | 一个能力的完整定义：manifest + 提示词/步骤图 + UI schema |
| 引擎 / driver | 真正执行任务的进程或服务，如 Claude Code、TTS worker |
| job | 一次能力执行实例，异步、可取消、可恢复 |
| 资产 / asset | 有类型、有版本、可再次被消费的产物 |
| 项目 / project | 资产与任务的归属容器，对应一部作品 |
| 租户 / tenant | 计费与隔离边界，个人或团队 |
| 内容链 | project 内 asset 的派生关系图 |
