# 10 路线图

假设团队 2–3 人（1 后端/平台、1 前端、1 媒体/算法，可重叠）。工期为自然周，含缓冲。

## 里程碑总览

```text
M0 骨架 ──→ M1 平台核心 ──→ M2 agent 驱动 + 通用壳 ──→ M3 有声链路 ──→ M4 剧本/分镜/视频 ──→ M5 商业化
 1 周         3 周              2–3 周                    3–4 周          4 周                持续
```

每个里程碑必须有可演示的端到端路径，不做「只有后端接口」的里程碑。

## M0 骨架（1 周）

**目标**：仓库能跑、契约能校验、CI 能拦人。

交付：
- monorepo + pnpm workspace + TS 严格模式
- `packages/contracts` 第一版：CapabilityManifest、JobEvent、AssetType、Driver 接口
- docker-compose：postgres / redis / minio
- control-plane 健康检查 + web 空白页
- CI：lint / typecheck / unit / boundaries
- ADR 0001–0005

退出标准：
- [ ] `pnpm dev` 一条命令起本地全栈
- [ ] `POST /healthz` 返回 ok，Web 能打开
- [ ] contracts 单测覆盖 manifest 校验的成功与失败样例
- [ ] 故意在 control-plane 里 import driver，CI 必须失败（边界规则有效）

## M1 平台核心（3 周）

**目标**：不接任何真实引擎，用 mock driver 跑通「提交 → 执行 → 事件 → 产物 → 资产」全链路。

交付：
- 多租户数据模型 + 迁移 + RLS
- 注册/登录/refresh/租户切换
- 项目与资产 CRUD、预签名上传、版本、内容链查询
- 能力注册表（扫描 capability 目录）+ manifest lint
- job 状态机 + 队列 + runner 骨架
- SSE 事件流（断线续传、心跳、终态）
- mock driver + driver 契约测试 6 条
- Web：登录、项目列表、能力列表、schema 表单、任务页
- 计量账本 + 配额预扣

退出标准：
- [ ] mock 能力端到端：上传 txt → 创建 job → 进度到 100% → 产物入库 → 可在项目里看到新版本
- [ ] 取消、超时、超预算三条路径均有测试
- [ ] 跨租户访问任何资源均返回 404（含资产下载）
- [ ] SSE 断线 30s 后带 Last-Event-ID 重连，事件不丢不重（按 seq 去重）
- [ ] 新增一个 mock 能力只改 `capabilities/` 目录，Web 自动出现入口

## M2 agent 驱动 + 通用壳（2–3 周）

**目标**：接入第一个第三方 agent，验证「引擎可插拔」。

交付：
- 沙箱管理器：容器生命周期、只读根、网络 none、资源限制、进程树终止
- Claude Code driver：stream-json 映射、session 续轮、取消、产物收集
- OpenCode driver spike（确定 server 模式可用性与命令）
- `novel.edit` 能力：分章、检索相关前文（RAG-lite）、续写/改写、版本落库
- 资产渲染器 v1：文本、音频、图片、下载
- 移动端壳：登录、项目列表、任务进度、文本/音频预览
- 错误分类与重试/续作 UI

退出标准：
- [ ] novel.edit 用 Claude Code 完成一次真实续写，产物版本可在 Web 打开并 diff
- [ ] 同一能力切到 mock driver 不改客户端、不改控制面代码
- [ ] 已悬空运行的 job 被取消后 30s 内容器与子进程全部消失（`ps` 校验）
- [ ] 沙箱内访问 `example.com` 失败；访问 manifest 白名单域名成功
- [ ] 移动端能收到 job 终态并播放音频产物

## M3 有声链路（3–4 周）

**目标**：第一条真正的媒体长任务，验证 GPU、断点、批量与成本。

交付：
- TTS worker：CosyVoice 本地 + DashScope 云端双路由
- 章节/角色识别、音色映射、分块合成、checkpoint
- audio-post：响度归一、章节标记、拼接
- `audiobook.render` 能力 + 音色映射控件
- `forEach` 扇出与按项重试
- GPU 节点 profile（compose / k8s）
- 成本预估与预算熔断
- 移动端音频播放与推送

退出标准：
- [ ] 10 万字、5 角色，云端路线 ≤30 分钟完成
- [ ] 跑到 60% 强制杀容器，重跑只补未完成块，总耗时显著小于全量
- [ ] 单章失败不阻塞其他章，最终状态为 succeeded 但带 `partialFailures` 明细
- [ ] 实际成本与预估偏差 ≤20%
- [ ] 断网/白名单外访问被拒绝，且错误可读

## M4 剧本 / 分镜 / 视频（4 周）

**目标**：内容链从文字延伸到成片，验证多能力串联。

交付：
- `script.generate`：主线抽取、分幕分场、剧本格式
- `storyboard.plan`：拆镜、结构化镜头描述、一致性校验
- video worker：分镜图 + Ken Burns + 转场 + 字幕 + 配音对齐
- `video.render` 能力
- 内容链图 UI（DAG，可基于任一资产运行下一道工序）
- Webhook（job/asset 事件）
- gVisor 可行性评估（coding.assist 前置）

退出标准：
- [ ] 一条链跑通：小说 → 剧本 → 分镜 → 有声 → 视频
- [ ] 内容链图能显示每个节点的版本与派生关系，点击可预览
- [ ] 3 分钟成片，音画同步偏差 <100ms
- [ ] 单个镜头失败可单独重跑，不影响已成功镜头

## M5 商业化与扩展（持续）

> 已交付（2026-11-14）：套餐与配额预设、用量明细与月度对账单、租户能力开关、项目模板、只读分享、项目评论、`coding.assist`。支付/发票 PDF、实时协作、多语言、模板市场、生成式视频与 OpenCode/dsh driver 明确 deferred，见 ADR-0013。
>
> P0 收口（2026-11-14）：真实百炼 TTS、租户凭据 AES-256-GCM 加密、Docker Postgres 全链路（剧本 → 分镜 → 有声 → 视频）验证完成，见 ADR-0015。
>
> 非 P0 收口（2026-11-14）：凭据轮换、账单对账/发票快照、指标端点、gVisor 运行时支持、模板市场、评论 SSE 完成；支付网关/FCM/OpenCode/生成式视频/i18n/协同编辑列为外部或产品阻塞，见 ADR-0016。
>
> 对外准备（2026-11-14）：支付 mock/http 与回调、可打印账单、推送服务端、Helmet/限流、负载脚本与基线完成；真实商户号/FCM 证书/i18n 文案仍需外部输入，见 ADR-0017。
>
> 第二阶段收口（2026-11-17）：Yjs 实时协作、Web/移动端 i18n、移动端 DAG/设置/评论/推送注册、控制面与 worker 模型网关、项目 ACL、邀请/邮件、备份演练完成；推送 SDK 经确认暂跳过。
>
> 第二阶段（2026-11-16）：`novel.edit` 章节级 RAG-lite、TTS 峰值归一与并发分块、视频镜头淡入淡出、Webhook 手动 replay 完成。跨租户管理后台、邀请流程、队列压测脚本、备份/恢复脚本已完成；多语言、实时协作、项目级 ACL、统一模型网关仍待推进。

- 计费账单、发票、套餐升级
- 管理后台：租户、配额覆盖、能力启停、driver 灰度
- 模板市场（项目模板、音色、分镜风格）
- 分享与协作（评论、只读分享链接）
- 多语言 UI
- `coding.assist` + OpenCode / dsh driver 正式接入
- 生成式视频模型作为镜头渲染 driver

## 商业化闸门（M3）

- 条款核对结论决定平台 key 池是否对正式用户开放；未通过则维持仅 BYOK。
- M3 只实现额度与硬上限，不做订阅续费、发票、退款、结转（M5）。
- 私有化（C）仅在出现付费意向客户后启动，不进入主线排期。

## 里程碑依赖

| 里程碑 | 依赖 | 可并行 |
|---|---|---|
| M1 | M0 | Web 壳与移动端壳可提前 |
| M2 | M1（job/事件/资产） | capability 内容设计可提前 |
| M3 | M2（沙箱、批量） | TTS worker 可在 M2 期间独立开发 |
| M4 | M3（音频产物） | 剧本/分镜能力可并行 |
| M5 | M3 | 计费可提前到 M2 |

## 不做什么（对应里程碑）

- M1 不接真实模型，避免把平台问题和模型问题混在一起
- M2 不做通用 agent 市场
- M3 不做实时协作
- M4 不做生成式视频（先跑通确定性合成）
- M5 之前不做桌面端
